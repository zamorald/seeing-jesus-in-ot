HTML and CSS Headings are available 1-6. The new

tag is not for addresses generally but specifically for contact info of this page or article (how to reach the author). Use the new dfn tag to highlight the first use of a term. New editorial tags point out editorial insertions and deletions , with optional attributes datetime for when and cite for the rationale. Think "track changes." Dates and times can now be captured. Written by Doctor Who on Thursday 21st November 2052 where the datetime attribute is machine readable `CCYY-MM-DD HH:II` or sections thereof (e.g., CCYY-MM; HH:II). The new mark tag highlights text; emphasis it is, but third-party, not original.

Use the tabindex attribute (takes integers) on links to allow logical tabbing through the page for better accessibility. But really, the best thing is to wrap the anchor tag around a complete description of where it goes rather than a small selection. If still necessary, add detail in the title attribute.

The new tag is for shorter, in-line quotations (as opposed to blockquote). HTMLDog seems to think the tag (or is it an attribute in this case?) is for links to web resources only; they recommend other types be handled as figure with caption.

Regarding images, HTMLDog notes: The width and height attributes are necessary because if they are excluded, the browser will tend to calculate the size as the image loads, instead of when the page loads, which means that the layout of the document may jump around while the page is loading. I note the alt tag should be considered required, as well.
